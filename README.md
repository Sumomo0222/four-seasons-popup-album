# 四季旅行记忆 · 3D 立体旅行相册

一本可以用浏览器打开的**纸艺立体书（Pop-up Book）**：四座虚构小城、四个季节、一整年旅程，全部由纸张折叠结构构成——书页合拢时，山与海都会自然压回平面。

**在线阅读**：https://sumomo0222.github.io/four-seasons-popup-album/

## 四个章节

| 章节 | 城市 | 纸艺结构 |
| --- | --- | --- |
| 01 冬 · 雪国列车 | 白泷町 | 雪山向书沟聚拢成 V 形、雪国线列车自纸面立起、松林与远景雪山多层景片、车票根随页立起 |
| 02 春 · 江南古镇 | 杏花镇 | 白墙民居夹河道成街巷、石桥拱片、摇橹船随页轻摇、樱花枝自页角立起、灯笼 |
| 03 夏 · 夏日海岛 | 青屿岛 | 三层海浪随开页**依次升起**、灯塔立于天光景片、帆船随浪摇晃 |
| 04 秋 · 秋日山野 | 栎霜岭 | 暮色山峰 V 形聚拢、A 形帐篷、篝火（带跳动的火光）、层林景片 |

照片以**拍立得、明信片、票根**三种纸件形式与书页相连（底部折页），随页面打开而立起。

## 交互

- **拖动书页 / 拖动底部滑杆**：控制书本开合角度，观察场景与照片从平面逐层展开、合拢时压回纸面
- **点击照片**：查看日期、地点、天气与一段碎片日记（拍立得 / 明信片 / 票根三种卡片样式）
- **自动播放**：按时间顺序翻页（冬→春→夏→秋），章节之间展示旅行路线卡片；旅程终点合上书本并回顾全程路线
- **上下拖动**调整视角，**滚轮 / 双指**缩放；方向键翻章，空格键开始 / 暂停自动播放
- 封面环衬印有全程**旅行路线图**

## 运行

纯静态站点，无构建步骤。任意静态服务器指向本目录即可：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000/
```

Three.js 已内置于 `vendor/`（无外部运行时依赖；Google Fonts 加载失败时自动回退本地楷体）。

## 目录结构

```
index.html          页面骨架 + UI
css/style.css       旅行手帖风格样式（响应式）
js/data.js          章节 / 城市 / 日记 / 路线数据
js/textures.js      纸艺贴图生成器（Canvas 程序化绘制全部画面）
js/scenes.js        立体书结构：折页机构 + 四章纸艺场景
js/main.js          开合驱动、翻页、自动播放、弹窗、相机
vendor/             three.module.min.js (r160)
```

## 实现说明

- **所有画面均为程序绘制**：16 张“照片”插画、4 组页面版式、封面 / 环衬路线图 / 后封、邮票、票根、纸层书芯等全部由 Canvas 2D 生成，无任何外部图片素材。
- **所有场景均为纸张折叠结构**：每个部件是一个绕折线（`stand` 底边折起 / `lean` 远端前倾 / 侧边折起）旋转的纸片，折叠角度由书本开合角驱动；书合拢（开合角→0）时全部回到 0°，压回平面。
- 城市与日记为**虚构示例内容**。
- 依赖：[three.js](https://threejs.org) (MIT)、[Ma Shan Zheng / Noto Serif SC](https://fonts.google.com/) (OFL)。
